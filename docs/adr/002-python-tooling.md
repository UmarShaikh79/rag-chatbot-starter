# ADR 002: Python tooling

Status: Accepted

## Decision

FastAPI, uv, Pydantic v2, pytest, ruff and Alembic. Python 3.12 or newer.

## Alternatives considered

Poetry, Django, Litestar.

## Why

Async-first, typed, fast installs, one linter and formatter.

## Consequences

Python 3.12+ is required.
