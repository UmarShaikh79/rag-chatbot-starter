# Code of Conduct

This project is for learners and experienced developers alike. We want it to be a place where
anyone can ask a basic question, make a mistake in public and get a kind, useful answer.

## What we expect

- Be respectful and patient, especially with people who are new. Everyone was once.
- Assume good intent; ask before you judge.
- Give feedback on the work, not the person, and say how to improve it.
- Accept feedback gracefully, and credit other people's work.

## What is not acceptable

- Harassment, insults, or demeaning comments about anyone's identity, background, experience
  level, language or abilities.
- Sexual language or imagery, threats, and personal attacks.
- Publishing someone's private information without their permission.
- Repeatedly derailing discussions or ignoring a request to stop.

## Scope

This applies in the repository (issues, pull requests, discussions, reviews) and wherever
someone represents the project.

## Reporting

Report a problem privately to the maintainer, [@UmarShaikh79](https://github.com/UmarShaikh79):
on the repository's **Security** tab choose **Report a vulnerability** and start the title with
"Conduct:". Only the maintainer sees it, and reports are kept confidential. The maintainer may
remove content, warn, or block anyone who breaks this code.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.
