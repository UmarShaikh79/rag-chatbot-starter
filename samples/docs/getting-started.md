# Getting started with Tidepool Notes

Tidepool Notes is a fictional note-taking app used as sample content for this template. It runs on the web, Windows, macOS, iOS and Android.

## Creating an account

You can sign up with an email address or with a Google or Apple account. After signing up, check your inbox for a verification email; it expires after 24 hours. Unverified accounts can create up to 20 notes but cannot share notebooks.

## Notebooks and notes

Notes live in notebooks. Every account starts with a notebook called Inbox, which cannot be deleted. You can nest notebooks up to three levels deep. A single note can be up to 25 MB, including attachments.

## Tags

Tags help you find notes across notebooks. Type # followed by a word in any note to create a tag. A note can carry up to 50 tags.

## Offline mode

The desktop and mobile apps keep a full copy of your notes on the device, so you can read and edit them offline. Changes sync automatically when you reconnect. The web app needs an internet connection.
